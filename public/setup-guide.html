WORKSPACE SETUP

From sample data to your client’s outreach.

The dashboard is built. The remaining step is connecting accounts owned by you or your client. No paid messaging automation is required.

Current state: integration-ready.
This package uses your configured Supabase database. Outlook and Pipedrive are only connected after their account owners authorize them.

1. Connect your Supabase project

  1. Provide the Supabase project URL or project reference to the person setting up this dashboard. Use a new, dedicated project for this client.
  2. Run the setup SQL in the Supabase SQL Editor. This creates leads, activities, deals, and encrypted integration storage. Run it once on a project where these tables do not already exist.
  3. Configure the server environment values below. Keep the secret key in the hosting platform’s secret settings; never paste it into a client-side field or commit it to source control.
Server settingValue
SUPABASE_URLYour Supabase project URL
SUPABASE_SECRET_KEYA Supabase secret key (or legacy service_role key)
INTEGRATION_ENCRYPTION_KEYA securely generated, stable random secret of at least 32 characters. Keep a backup.
APP_URLThe exact deployed dashboard origin, without a trailing slash

This manual edition has no sign-in. Everyone who can reach the URL can view and edit data and manage connections. Database keys are used on the server only; the Supabase tables still deny direct browser access.

2. Connect Pipedrive

  1. In the client’s Pipedrive account, open Personal preferences → API. Official token instructions.
  2. Open Connections → Connect Pipedrive. Enter the company subdomain and the existing API token. Pulse verifies the account before saving the encrypted token.
  3. Click Sync now. Keep the Connections view open. Contacts sync first, then deals, then activities. Failed or large syncs can be resumed.

This requires the client’s existing Pipedrive subscription and API access. Pipedrive quotas still apply. No new token is purchased or created by this dashboard.

3. Connect Outlook / Microsoft 365

  1. Sign in to Microsoft Entra admin center using the client’s organization account and open App registrations → New registration. For one client organization, use a single-tenant app and its directory tenant ID. For Outlook.com personal accounts, register an app that permits personal Microsoft accounts.
  2. Add a Web redirect URI:
    YOUR_DASHBOARD_ORIGIN/api/oauth/microsoft/callback
  3. Under Microsoft Graph API permissions, use delegated permissions: User.Read and Mail.Read. Pulse also requests offline_access so it can refresh the connection. It requests no sending or mailbox-write permissions. Your organization may require administrator consent.
  4. Create a client secret in the Microsoft app registration. Configure MICROSOFT_CLIENT_ID, MICROSOFT_CLIENT_SECRET, and MICROSOFT_TENANT_ID as server environment settings. Use the secret’s value, not its ID. Store its expiry date and replace it before it expires. APP_URL must exactly match the dashboard’s origin.
  5. In Connections → Connect Outlook, have the client sign in and authorize their mailbox.
  6. Create an Outlook category named Outreach and apply it to the sent emails and replies you want the client to monitor. Categories do not automatically propagate to every reply; categorize new messages or use an Outlook rule.
  7. Import your leads or sync Pipedrive first. Then click Sync now on the Outlook card.

Pulse imports subject and preview text (up to 255 characters), timestamps, and direction from categorized messages received in the last 90 days that match saved lead emails. Drafts and unrelated messages are excluded. It does not send email or import attachments. It currently connects the signed-in user’s own mailbox; shared/delegated mailboxes require a separate integration change.

What is needed from the account owner: a Microsoft app registration plus authorization to read the mailbox. Public API documentation cannot supply private client credentials. The build uses Microsoft Graph’s standard mail API with your existing Outlook account, with no paid automation service. Tenant policies and existing Microsoft licensing still apply. See Mail.Read permissions and Microsoft OAuth setup.

4. LinkedIn and WhatsApp

Use Log activity after an outreach action, or upload a CSV under Leads → Import CSV. Log messages, replies, positive replies, connection requests, and meetings. LinkedIn messaging access is restricted; WhatsApp business messaging has its own eligibility and pricing. This build uses no unofficial scraping tools or paid messaging APIs.

5. Your daily workflow

  1. Import leads or sync Pipedrive.
  2. Log LinkedIn and WhatsApp outreach, or import your completed activity sheet.
  3. Categorize Outlook outreach and sync it from Connections.
  4. Your client opens the dashboard to see activity, filter channels, inspect timelines, and export reports.

What the numbers mean

Leads contacted: distinct leads with a sent message or connection request within the selected period. Messages sent: sent messages plus connection requests. Reply rate: the percentage of contacted leads with at least one reply in that same period. Positive replies count as replies. Meetings: recorded meeting-booked activities. A manually entered meeting and the same meeting synced from Pipedrive can count twice; choose one source for each event.

Pipeline: a current Pipedrive snapshot, separate from the activity date filter. Different currencies are reported separately. New Pipedrive contacts start at New; lead statuses are managed in the dashboard, while deal stages remain synced from Pipedrive. Archived/deleted deals disappear after the next complete sync; historical contacts and activities are retained.

Costs and limits

There are no paid integration services built into Pulse. Supabase’s free plan and provider quotas still apply. Check your hosting plan separately; this build has not enabled any paid upgrades. The current workspace supports up to 50,000 rows per table, imports of 500 rows, and one connected Outlook mailbox and Pipedrive company. Outlook imports preview snippets, not full message bodies or attachments.
